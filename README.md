
# Ciberseguridad CI/CD

## Descripción del proyecto

Proyecto académico de Ingeniería Web correspondiente
al tercer corte.

El objetivo es implementar control de versiones
mediante Git, GitHub y GitLab, además de configurar
un pipeline de integración y despliegue continuo
(CI/CD).

## Objetivos

- Configurar un repositorio local con Git.
- Publicar el proyecto en GitHub.
- Importar el repositorio a GitLab.
- Implementar un pipeline CI/CD.
- Ejecutar pruebas de integridad.
- Verificar el proceso de despliegue.
- Aplicar conceptos básicos de ciberseguridad.

## Tecnologías

- Git
- GitHub
- GitLab
- GitLab CI/CD
